# 🌐 VeriVoice – UNESCO Youth Hackathon 2026

VeriVoice is an AI-powered multilingual voice fact verification platform that leverages a collaborative multi-agent architecture to analyze speech, verify factual claims, retrieve trusted evidence, and generate explainable AI verification reports.

> 🚧 **Project Status:** In Progress

---

## 🚀 Tech Stack

### Frontend
- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Shadcn/UI

### AI & Backend
- Google Gemini API
- Python FastAPI
- MongoDB Atlas
- Mongoose

---

## ✨ Planned Features

- 🎤 Voice Upload & Live Recording
- 📝 AI Speech Transcription
- 🌍 Multilingual Support
- 🤖 Multi-Agent AI Workflow
- ✅ AI Fact Verification
- 📚 Trusted Evidence Retrieval
- 📊 Explainable AI Reports
- 📈 Real-Time Verification Dashboard
- 📱 Fully Responsive UI

## 🏗️ Project Status

Currently under active development for the **UNESCO Youth Hackathon 2026**.
